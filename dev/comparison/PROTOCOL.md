# Comparison Protocol — MATLAB vs Python MGGP

**Goal:** run both implementations on the exact same dataset and hyperparameters, then
compare quality and speed side-by-side with reproducible numbers.

## Dataset

| Property | Value |
|---|---|
| System | `y(k) = 0.75·y(k-2) + 0.25·u1(k-1) − 0.20·y(k-2)·u1(k-1)` |
| N | 1000 samples |
| Seed | `rng(42)` (MATLAB) / `numpy.random.seed(42)` (Python, via rng(42) match) |
| Split | 70 % identification (700 samples) / 30 % validation (300 samples) |
| File | `data/siso_ref.csv` — generated by MATLAB `generate_dataset.m`; Python reads the same CSV |

**Important:** Python does NOT regenerate the dataset. Both sides read the same CSV so inputs
are bit-for-bit identical.

## Known structural differences (do NOT try to fix)

These are architectural limitations documented in `CLAUDE.md` under "Limitações de paridade":

- **G4-A1 — Lag offset:** Python `q_i` ≈ MATLAB `q_{i+1}` in absolute-lag terms.
  A Python model with `q1(y)` uses lag 2 from the target; MATLAB `q1(y)` uses lag 1.
  **Results are NOT directly comparable at the term/structure level — only at the quality
  metric level (RMSE, convergence).**
- **G4-A2 — GP tree depth vs flat products:** Python uses nested DEAP trees; MATLAB uses
  flat products. The hypothesis spaces differ.
- **G4-A3 — Crossover/mutation operators:** Different operators, different dynamics.
- **G4-A4 — Valid sample count:** Python P has N−lagMax−1 rows; MATLAB has N−lagMax.

## Quality threshold

- **Pass:** MATLAB FR-RMSE (val) ≤ Python FR-RMSE (val) × 1.2 (within 20 %)
- GP is stochastic; exact match not expected across 3 seeds

## Metrics collected (per seed, then mean ± std)

| Metric | Unit | How |
|---|---|---|
| Wall-clock time | seconds | `tic/toc` (MATLAB) / `time.perf_counter()` (Python) |
| Time per generation | ms | wall / nGeracoes |
| Throughput | eval/s | (popSize × nGeracoes) / wall |
| Peak RAM | MB | `feature('memstats')` (MATLAB) / `tracemalloc` (Python) |
| OSA-RMSE val | — | one-step-ahead on validation set |
| FR-RMSE val | — | free-run on validation set |
| Convergence gen | generation | first gen where best fitness < 0.05 |

## How to run

1. In MATLAB: `run generate_dataset` (creates `data/siso_ref.csv`)
2. Verify Python can read it: `python generate_dataset.py`
3. Run Python bench: `python bench_python.py`
4. Run MATLAB bench: open MATLAB in this directory, `run bench_matlab_vs_python`
5. Compare: `run compare_results` (MATLAB)

Results land in `results/` (gitignored).
